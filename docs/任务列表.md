# Tagger 任务列表

> 更新日期：2026-08-20
>
> 约定：已验证完成的任务使用 `[x]`；只完成了界面草稿或部分链路的任务保留 `[ ]`，并在备注中说明边界。

## 已实现

### 曲库与内嵌元数据

- [x] 浏览音乐目录和曲目列表，支持 MP3、FLAC、WAV。
- [x] 曲库工具栏支持按 MP3/FLAC/WAV 筛选，并支持专辑、标题、最近修改和格式排序。
- [x] 设置页读取当前曲库名称、根目录、曲目/文件夹数量和可写状态，并可触发真实重新扫描；目录根路径仍由启动参数配置。
- [x] 读取并编辑标题、艺术家、专辑、专辑艺术家、音轨/光盘号、年份、风格、歌词。
- [x] 读取技术信息、原始 TagLib PropertyMap、嵌入封面数量。
- [x] 使用 revision 冲突保护、临时副本、写后重读校验和原子替换。
- [x] 记录标签/封面修改历史，并支持预览和恢复。
- [x] 通过 HTTP Range 流播放真实音频；Mock 模式提供可操作的试听占位。
- [x] 播放器提升为跨页面的全局播放器，切换曲库、任务、历史、设置页面时保持当前曲目和播放状态。
- [x] 封面默认显示空白占位；设置页可选择是否使用生成式占位，并同步应用到曲库、候选、审核和历史页面。
- [x] 匹配详情和曲目检查器展示已嵌入/远程封面的实际像素尺寸与文件大小；写入前可选择原图、居中裁剪至 1000×1000 或 500×500。
- [x] 批量编辑面板支持用同一张图片替换/删除多首曲目的嵌入封面，并可在写入前选择原图、1000×1000 或 500×500。
- [x] 封面写入和删除成功后立即使用后端返回的重读曲目快照刷新封面数量、像素尺寸和文件大小。
- [x] 曲目检查器提供单曲“重新读取当前文件”操作，只扫描并更新当前文件，不触发整库扫描。
- [x] 兼容旧版 SQLite 扫描记录中缺失的扩展数组字段，避免打开曲库或完成标签/封面/歌词操作时因 `null` 数组导致前端崩溃。

### 数据源与审核

- [x] Provider 策略接口、MusicBrainz、LRCLIB、Apple/iTunes，以及默认关闭、可按需启用的网易云、酷我和酷狗实验性适配器。
- [x] 候选搜索、字段选择、歌词/封面显式采用和安全下载写入。
- [x] 候选抽屉支持编辑标题、艺术家、专辑后重新查询，并保留文件 ID 作为查询上下文。
- [x] 审核页支持跳过、接受后自动进入下一首，以及在多个候选之间切换。
- [x] 创建写入任务时将接受的匹配项更新为 `write_pending`，保留选中的候选 ID。

### 任务中心与工程

- [x] SQLite 持久化扫描、匹配、写入、批量编辑任务，支持取消、失败项重试和 SSE/轮询快照恢复。
- [x] 任务中心状态 Tab（全部、进行中、待审核、失败）可用，并展示批量任务逐文件结果和字段 diff。
- [x] 顶部导航只保留实际可用操作；移除无效的快捷键、通知、用户头像入口和常驻任务红点。
- [x] 修改历史支持按来源和最近 30 天筛选，筛选结果与当前详情联动。
- [x] 系统设置展示实际启动监听地址但不允许运行时修改；历史查看/保留选项支持最近 3、5、10、20 次。
- [x] 封面占位和写前历史开关改为紧凑滑动开关，默认封面占位仍为空白。
- [x] 全局播放器固定在顶部导航栏右侧，跨页面保持播放，支持播放/暂停、单曲循环、进度拖动和无选曲提示；浅色主题使用更明亮的象牙白背景。
- [x] React 19 + Vite + Tailwind 前端编译后嵌入 Go 单二进制。
- [x] 前端测试、Go 单元测试、竞态检查和 TestMusic 集成验证已建立。
- [x] 保留同名 `.lrc` 的只读兼容与历史显示；前端写入主线只修改音频内嵌标签，不再提供 `.lrc` 保存入口。

## 未实现 / 后续主线

### 内嵌元数据主线（优先）

- [x] 扩展统一 `TagPatch` 和扫描模型，覆盖 COMMENT、COMPOSER、CONDUCTOR、LYRICIST、BPM、ISRC、MusicBrainz/AcoustID 标识等常见内嵌字段。
- [x] 为 MP3/FLAC/WAV 分别验证上述字段的读取、写入、删除、空值和多值语义，补齐真实音频集成测试。
- [x] 在 Inspector 中增加“基础字段 / 扩展字段 / 原始键”分层编辑，避免把格式专有键误写到其他格式。
- [x] 完善批量编辑与审核的字段策略，使注释、作曲家、指挥、作词家、版权、BPM、ISRC 等扩展字段可以逐字段选择、预览、冲突重试和审计；识别 ID 仍要求逐曲目确认。
- [x] 持久化审核任务中的“接受 / 跳过 / 更换候选”状态，以及字段 checkbox 和封面选择；从任务中心重新打开同一个匹配任务时会恢复完整审核快照，最终写入任务创建后接受项会落为 `write_pending`。

### 数据源体验

- [x] 候选结果提供经过后端安全代理的封面预览；当前未下载或预览失败的远程封面默认保持空白，不再用自动生成图干扰审核，并兼容桌面 HTTP(S) 代理、CDN MIME 别名/错误声明和安全重定向。
- [x] 增加候选来源筛选、审核状态筛选、按曲目保存查询历史，并支持重新匹配后替换当前任务候选快照。
- [x] 网易云补齐歌曲搜索、同步歌词、别名和专辑封面；MusicBrainz 补充 Cover Art Archive 能力；酷我兼容短图字段和 HTTPS 封面 URL；新增酷狗搜索、LRC 下载解码和歌曲封面策略。
- [x] LRCLIB 增加无艺术家、版本后缀和精确查询 404 后的宽搜索兜底；歌词焦点优先展示含歌词的候选。
- [x] 酷我候选补充当前 JSON 歌词接口，并保留旧 RID/歌词 key 接口回退；时间字段统一转换为可编辑的 LRC。
- [x] 歌词编辑框移除每行背景分隔线，保留等宽编辑和时间轴可读性。
- [x] 设置页数据源测试支持自定义歌曲查询，使用可关闭的浮动诊断面板展示候选、可展开歌词、封面可用性及封面探测/抓取结构化日志。
- [x] 歌词匹配抽屉直接展示远程歌词，支持写入前手动修改，并将编辑后的内容写入音频内嵌歌词标签。
- [x] 全局辅助文字字号下限提升到 11px，降低密集页面的阅读压力。
- [x] 数据源卡片的实验性提示与配额说明改为自适应布局；诊断面板中的远程封面固定为方形裁切展示。
- [ ] 完善网易云/酷我/酷狗接口的授权、长期兼容和错误提示，并继续确保实验性接口不是唯一依赖。

### 文件与批量操作

- [x] 批量内嵌标签编排支持公共字段设置/追加/删除、文本查找替换、顺序编号和规则模板；逐文件状态、失败重试和跨文件部分失败恢复仍沿用 batch_edit worker。
- [x] 批量编辑面板支持保存、载入和删除可复用字段规则模板；模板不绑定曲目列表，仍通过真实模式 batch job 执行。
- [x] 增加 JSON/CSV 内嵌标签快照导入导出、按曲目差异预览，以及带 revision 冲突保护的会话内撤销导入。
- [x] 提供可选的单用户访问令牌（`--auth-token` / `TAGGER_AUTH_TOKEN`）；未配置令牌时不启用鉴权，配置后仅 API 需要 Bearer 令牌。
