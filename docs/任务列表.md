# Tagger 任务列表

> 更新日期：2026-08-20
>
> 约定：已验证完成的任务使用 `[x]`；只完成了界面草稿或部分链路的任务保留 `[ ]`，并在备注中说明边界。

## 已实现

### 曲库与内嵌元数据

- [x] 浏览音乐目录和曲目列表，支持 MP3、FLAC、WAV。
- [x] 读取并编辑标题、艺术家、专辑、专辑艺术家、音轨/光盘号、年份、风格、歌词。
- [x] 读取技术信息、原始 TagLib PropertyMap、嵌入封面数量。
- [x] 使用 revision 冲突保护、临时副本、写后重读校验和原子替换。
- [x] 记录标签/封面修改历史，并支持预览和恢复。
- [x] 通过 HTTP Range 流播放真实音频；Mock 模式提供可操作的试听占位。
- [x] 播放器提升为跨页面的全局播放器，切换曲库、任务、历史、设置页面时保持当前曲目和播放状态。
- [x] 封面默认显示空白占位；设置页可选择是否使用生成式占位，并同步应用到曲库、候选、审核和历史页面。
- [x] 兼容旧版 SQLite 扫描记录中缺失的扩展数组字段，避免打开曲库或完成标签/封面/歌词操作时因 `null` 数组导致前端崩溃。

### 数据源与审核

- [x] Provider 策略接口、MusicBrainz、LRCLIB、Apple/iTunes，以及默认关闭的网易云/酷我实验性适配器。
- [x] 候选搜索、字段选择、歌词/封面显式采用和安全下载写入。
- [x] 候选抽屉支持编辑标题、艺术家、专辑后重新查询，并保留文件 ID 作为查询上下文。
- [x] 审核页支持跳过、接受后自动进入下一首，以及在多个候选之间切换。
- [x] 创建写入任务时将接受的匹配项更新为 `write_pending`，保留选中的候选 ID。

### 任务中心与工程

- [x] SQLite 持久化扫描、匹配、写入、批量编辑任务，支持取消、失败项重试和 SSE/轮询快照恢复。
- [x] 任务中心状态 Tab（全部、进行中、待审核、失败）可用，并展示批量任务逐文件结果和字段 diff。
- [x] React 19 + Vite + Tailwind 前端编译后嵌入 Go 单二进制。
- [x] 前端测试、Go 单元测试、竞态检查和 TestMusic 集成验证已建立。
- [x] 同名 `.lrc` sidecar 支持独立读写、历史和恢复；它是可选兼容能力，不作为音频内嵌元数据主线。

## 未实现 / 后续主线

### 内嵌元数据主线（优先）

- [x] 扩展统一 `TagPatch` 和扫描模型，覆盖 COMMENT、COMPOSER、CONDUCTOR、LYRICIST、BPM、ISRC、MusicBrainz/AcoustID 标识等常见内嵌字段。
- [x] 为 MP3/FLAC/WAV 分别验证上述字段的读取、写入、删除、空值和多值语义，补齐真实音频集成测试。
- [x] 在 Inspector 中增加“基础字段 / 扩展字段 / 原始键”分层编辑，避免把格式专有键误写到其他格式。
- [x] 完善批量编辑与审核的字段策略，使注释、作曲家、指挥、作词家、版权、BPM、ISRC 等扩展字段可以逐字段选择、预览、冲突重试和审计；识别 ID 仍要求逐曲目确认。
- [x] 持久化审核任务中的“接受 / 跳过 / 更换候选”状态，以及字段 checkbox 和封面选择；从任务中心重新打开同一个匹配任务时会恢复完整审核快照，最终写入任务创建后接受项会落为 `write_pending`。

### 数据源体验

- [x] 候选结果提供经过后端安全代理的封面预览；当前未下载或预览失败的远程封面默认保持空白，不再用自动生成图干扰审核。
- [x] 增加候选来源筛选、审核状态筛选、按曲目保存查询历史，并支持重新匹配后替换当前任务候选快照。
- [ ] 完善网易云/酷我接口的授权、长期兼容和错误提示，不把实验性接口作为默认依赖。

- [ ] 增加导入/导出标签快照、CSV/JSON 变更预览和可撤销批量操作。
