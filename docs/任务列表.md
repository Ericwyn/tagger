## 已实现

### 曲库与内嵌元数据

- [x] 浏览音乐目录和曲目列表，支持 MP3、FLAC、WAV。
- [x] 曲目列表改为服务端过滤、排序和游标分页，默认首批 100 首、单页最多 200 首，滚动到底部自动追加，避免打开首页时一次读取整座曲库。
- [x] 曲库页在同一 SPA 会话内缓存已加载页、筛选/排序、跨页选择、当前曲目和 Virtuoso 滚动状态；离开到任务、历史、设置或审核页后返回可恢复原视图，整页刷新只持久化轻量筛选和滚动锚点。
- [x] 新增曲目解析 API，审核页、任务页和批量操作按曲目 ID 或当前结果集解析，单次最多 1000 首并对超限结果给出缩小范围提示。
- [x] 曲库工具栏支持按 MP3/FLAC/WAV 筛选，并支持专辑、标题、最近修改和格式排序。
- [x] 设置页读取当前曲库名称、根目录、曲目/文件夹数量和可写状态，并可触发真实重新扫描；目录探测通过后可在没有活动任务时排队切换曲库，根目录会持久化到 SQLite。
- [x] 读取并编辑标题、艺术家、专辑、专辑艺术家、音轨/光盘号、年份、风格、歌词。
- [x] 读取技术信息、原始 TagLib PropertyMap、嵌入封面数量。
- [x] 使用 revision 冲突保护、临时副本、写后重读校验和原子替换。
- [x] 记录标签/封面修改历史，并支持在历史页查看差异、加载修订快照到编辑器。
- [x] 历史页恢复改为加载目标修订的标签快照到曲目编辑器草稿；用户可继续调整并通过安全写入确认，历史页不再直接改写文件。
- [x] 历史快照兼容封面/sidecar-only 记录和旧快照中的 `null` 数组；加载快照不会因可选数组缺失而白屏。
- [x] 曲目检查器在窄窗口下保持标签页、表单和保存操作栏收缩，历史快照提示不会造成横向溢出。
- [x] 通过 HTTP Range 流播放真实音频；Mock 模式提供可操作的试听占位。
- [x] 播放器提升为跨页面的全局播放器，切换曲库、任务、历史、设置页面时保持当前曲目和播放状态。
- [x] 封面默认显示空白占位；设置页可选择是否使用生成式占位，并同步应用到曲库、候选、审核和历史页面。
- [x] 匹配详情和曲目检查器展示已嵌入/远程封面的实际像素尺寸与文件大小；写入前可选择原图、居中裁剪至 1000×1000 或 500×500。
- [x] 批量编辑面板支持用同一张图片替换/删除多首曲目的嵌入封面，并可在写入前选择原图、1000×1000 或 500×500。
- [x] 封面写入和删除成功后立即使用后端返回的重读曲目快照刷新封面数量、像素尺寸和文件大小。
- [x] 曲目检查器提供单曲“重新读取当前文件”操作，只扫描并更新当前文件，不触发整库扫描。
- [x] 兼容旧版 SQLite 扫描记录中缺失的扩展数组字段，避免打开曲库或完成标签/封面/歌词操作时因 `null` 数组导致前端崩溃。

### 数据源与审核

- [x] Provider 策略接口、MusicBrainz、LRCLIB、Apple/iTunes，以及默认关闭、可按需启用的网易云、酷我和酷狗实验性适配器。
- [x] 候选搜索、字段选择、歌词/封面显式采用和安全下载写入。
- [x] 候选抽屉支持编辑标题、艺术家、专辑后重新查询，并保留文件 ID 作为查询上下文。
- [x] 审核页支持跳过、接受后自动进入下一首，以及在多个候选之间切换。
- [x] 审核页改为紧凑工作台：批量接受、保存草稿和确认写入集中到顶部，右侧曲目操作随详情滚动固定，左侧当前曲目使用高对比选中态；本地没有封面且候选有封面时默认勾选替换封面。
- [x] 创建写入任务时将接受的匹配项更新为 `write_pending`，保留选中的候选 ID。
- [x] 写入 worker 完成后回收父抓取任务状态：全部曲目已写入/跳过且无失败时标记为已完成，成功和失败并存时标记为部分完成，全部失败时标记为失败，仍有未处理曲目则继续保留待审核；失败/部分完成的匹配任务仍可重新打开审核。

### 任务中心与工程

- [x] SQLite 持久化扫描、匹配、写入、批量编辑任务，支持取消、失败项重试和 SSE/轮询快照恢复。
- [x] 任务中心状态 Tab（全部、进行中、待审核、失败）可用，并展示批量任务逐文件结果和字段 diff。
- [x] 统一任务计数与终态语义：处理进度只表示已尝试项，`partial` 仅表示至少一项成功且仍有失败；全部失败使用 `failed`。写入/批量编辑详情分别展示处理、成功、失败数量，历史不一致快照由 migration 修复。
- [x] 批量写入和批量编辑入队前执行有效权限预检，真实验证源文件可读及每个目录可创建/删除同级临时文件；不可写时返回明确的容器 UID/GID 或只读挂载提示，不创建注定失败的任务。
- [x] 顶部导航只保留实际可用操作；移除无效的快捷键、通知、用户头像入口和常驻任务红点。
- [x] 修改历史支持按来源和最近 30 天筛选，筛选结果与当前详情联动。
- [x] 系统设置展示实际启动监听地址但不允许运行时修改；历史保留策略支持最近 3、5、10、20 次，SQLite 会按曲目剪枝旧修订，历史列表同步使用该上限。
- [x] 设置页默认进入音乐目录；系统信息展示 SQLite/封面缓存占用和远程缓存条目，并支持清理可重新生成的运行缓存（不删除音乐文件、标签历史或数据库）。
- [x] 封面占位和写前历史开关改为紧凑滑动开关，默认封面占位仍为空白。
- [x] 全局播放器固定在顶部导航栏右侧，跨页面保持播放，支持播放/暂停、单曲循环、进度拖动和无选曲提示；浅色主题使用更明亮的象牙白背景。
- [x] React 19 + Vite + Tailwind 前端编译后嵌入 Go 单二进制。
- [x] 前端测试、Go 单元测试、竞态检查和 TestMusic 集成验证已建立。
- [x] 保留同名 `.lrc` 的只读兼容与历史显示；前端写入主线只修改音频内嵌标签，不再提供 `.lrc` 保存入口。
