# 批量抓取立即进入任务中心

## 已完成

- 从曲库页启动批量抓取后，真实后端返回任务 ID 即立即跳转任务中心。
- 任务中心自动聚焦新建的抓取任务，展示处理数、候选数、最新事件和进度条。
- 任务运行期间可直接使用已有的取消任务按钮；任务完成为待审核后，再从任务详情打开审核页。
- 只有从任务中心重新打开已有任务时，审核页才会读取候选快照并进入审核流程，不再阻塞在新任务的等待页。
- Mock 模式仍保持即时原型审核流程，不改变现有前端演示体验。
