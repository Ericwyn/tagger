# 歌词候选聚焦

验证日期：2026-08-20

## 交互

歌词 Inspector 的“查找歌词”现在会：

1. 使用当前曲目的标题、艺术家、专辑和时长查询现有 Provider Registry。
2. 打开同一个候选抽屉，但传入 `lyrics` focus。
3. 在候选提供歌词时默认勾选歌词资产；用户仍可取消勾选或选择其他字段。
4. 采用候选时继续经过显式字段 patch、revision guard 和安全写入流程。

从标签或封面页进入搜索时保持原有 metadata focus，不会意外勾选歌词。

## 测试

- CandidateDrawer 测试覆盖歌词 focus 自动勾选。
- TrackInspector 测试覆盖歌词页按钮传递 `lyrics` focus。
- 全部前端测试和 TypeScript 检查继续通过。

## 边界

当前仍使用现有候选抽屉写入 `LYRICS` 标签；同步 `.lrc` sidecar 的独立保存开关仍按设计作为后续文件写入能力实现。
