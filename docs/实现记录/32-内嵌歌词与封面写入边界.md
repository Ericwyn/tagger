# 内嵌歌词与封面写入边界

> 记录日期：2026-08-20

## 产品边界

- 歌词编辑和候选应用只写入音频文件的内嵌标签（MP3/FLAC/WAV 的对应 metadata）。
- 前端移除“同时保存 `.lrc`”选项，避免用户误以为一次保存会产生两个独立事实来源。
- 已有同名 `.lrc` 仍保留后端只读兼容、历史展示和迁移空间；本次不主动删除用户文件，也不改变旧 API，避免升级时造成数据损失。

## 候选资源选项

候选抽屉和审核页中的资源选择现在明确标注为“同时写入封面”和“同时写入歌词”：

- 勾选封面：下载候选图片并嵌入当前音频；不勾选则只应用选中的文字/数值标签。
- 勾选歌词：将候选歌词写入音频标签；不勾选则保留文件当前歌词。

## 封面链路修复

1. 封面客户端在配置了 `HTTP(S)_PROXY` 的桌面环境中使用系统代理；没有代理时仍使用 provider allowlist + DNS 公网地址校验的直连路径。
2. 图片 MIME 校验接受 `image/jpg`、`image/pjpeg` 和 `image/x-png` 这些常见 CDN 别名；对远程 Provider 封面忽略不可靠的声明 MIME，继续以实际图片字节为准验证格式、尺寸和大小（本地上传仍严格校验声明类型）。
3. MusicBrainz 描述补充封面能力；其 Cover Art Archive 的归档重定向仍受 provider allowlist 约束。
4. 酷我兼容 `ALBUMPIC`、`web_albumpic`、`web_albumpic_short` 等字段，并把短路径转换为 HTTPS 的 500px 封面 URL。

酷我短路径的构造参考了 [musicdl 的 Kuwo 图片处理](https://github.com/CharlesPikachu/musicdl/blob/master/musicdl/modules/common/gdstudio.py#L725-L731)；该来源同样使用 `img*.kwcdn.kuwo.cn/star/albumcover/` 和 120px → 更大尺寸的路径规则。
