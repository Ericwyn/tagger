# v1.0.2 发布说明

## 数据源与封面

- MusicBrainz 增加独立的 Internet Archive 下载基址配置，默认仍为 `https://archive.org`。
- Cover Art Archive 返回的 `archive.org/download/...` 重定向可以安全改写到 HTTPS 镜像，也支持 `https://proxy.example/https/archive.org` 这类带路径前缀的通用代理。
- 数据源测试、候选封面预览、后台写入和磁盘缓存统一使用配置感知的封面下载入口，并继续执行主机白名单、重定向和图片内容校验。

## 任务状态与安全写入

- 统一任务计数与终态：全部失败使用 `failed`，成功和失败并存才使用 `partial`；100% 明确表示处理进度而不是成功率。
- 写入和批量编辑详情分别显示已处理、成功、失败数量，并保留最近一次失败原因。
- 新增任务计数不变量检查和 SQLite migration，自动修正旧版本中“成功 0、失败 N，却显示部分完成”的历史任务。
- 批量写入与批量编辑入队前真实探测每个目标目录能否创建同级临时文件，不可写时直接返回可操作的权限提示，不创建注定失败的任务。
- 修复标签写入成功、后续封面失败时同一曲目被同时计入成功和失败的问题；已发生的标签变更仍会重新索引并写入历史。
- 重试覆盖取消前缺失或仍为 pending 的项目，并把总数更新为实际重试项数量；失败/部分完成的匹配任务仍可重新打开审核。

## Docker 部署

- 镜像继续默认以非 root 的 `10001:10001` 运行。
- README 增加 Docker `--user UID:GID`、Compose `user:`、UID/GID 查询、共享组及 `/music`、`/data` 权限说明，便于适配宿主机和 NAS 的目录所有权。

## 验证

- Go 全量测试、静态检查、构建以及任务相关竞态测试通过。
- 前端 128 个测试、TypeScript 检查和 Vite 生产构建通过。
