# 扩展内嵌元数据字段

验证日期：2026-08-20

## 已完成

- 统一领域模型增加注释、作曲家、指挥、作词家、版权、BPM、ISRC、MusicBrainz Track/Release/Artist ID、AcoustID 和指纹字段。
- scanner 从 TagLib PropertyMap 读取这些字段，兼容常见别名（例如 `TBPM`、`MUSICBRAINZ_RELEASEID`），空的多值字段保持为空数组。
- 安全 writer 支持 set/delete/merge 语义、数值范围校验、写后重读验证、revision 冲突保护、历史 diff 和恢复。
- 候选模型保留扩展字段；MusicBrainz 候选会带回 recording/release/artist 标识，审核和候选抽屉可选择这些字段。
- Inspector 将扩展字段放入折叠面板，基础字段、扩展字段和原始 PropertyMap 分层展示。

## 验证

- fake engine scanner 测试覆盖全部扩展字段归一化。
- memory engine writer 测试覆盖 12 个扩展字段的 patch 与 diff。
- TestMusic 复制语料以及现场生成 WAV 的 MP3/FLAC/WAV 写后重读测试通过；源文件不会被修改。
- 前端 48 tests、TypeScript 检查以及 Go 全量测试通过。
