# 数据源诊断测试

> 记录日期：2026-08-20

## 功能

设置 → 数据源中的“测试查询”现在不是固定的连通性探测。选择已启用来源后，可以输入歌曲名、歌手、专辑和时长，执行真实搜索并查看：

- 数据源状态、候选数量、耗时和缓存命中情况；
- 每个候选的标题、艺人、专辑、匹配分数，以及是否提供歌词/封面；
- 结构化抓取日志：查询参数、候选 ID/外部 ID、歌词字符数、封面引用域名和过期时间；
- 可选的封面探测结果：经过同一套 HTTPS allowlist、代理、重定向、MIME、尺寸和大小校验，记录成功的 MIME/格式/尺寸/字节数，或失败原因。

## 接口边界

`POST /api/v1/providers/:id/test` 继续兼容空请求体（使用默认示例查询），也接受：

```json
{
  "query": {
    "title": "再回首",
    "artists": ["姜育恒"],
    "album": "多年以后",
    "durationSeconds": 248
  },
  "limit": 5,
  "probeArtwork": true
}
```

封面探测只在诊断请求显式传入 `probeArtwork` 时执行，避免旧版连接测试额外触发图片下载；候选封面仍通过短期 candidate ID 引用，不直接把远程 URL 暴露给前端。
