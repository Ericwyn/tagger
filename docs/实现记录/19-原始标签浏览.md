# 原始标签浏览

验证日期：2026-08-20

## API

新增 `GET /api/v1/tracks/:id/raw-tags`：

- 只接受已索引曲目 ID，并通过 `filewrite.Writer.ReadRawTags` 复用同一套根目录、相对路径和符号链接安全校验。
- 返回 `trackId`、当前 `revision` 和 TagLib `PropertyMap` 风格的 `map[string][]string`，不会把多值标签压成字符串。
- 失败时区分曲目不存在、文件越界/不存在和 TagLib 读取错误；成功响应返回 ETag。

## 前端

Inspector 标签页的“查看原始标签”按钮现在按需请求文件，展开可滚动键值面板。键名保持原样（例如 `TITLE`、`TXXX:*`、`MUSICBRAINZ_*`），数组值使用分隔展示；Mock 模式用当前规范化字段生成可交互预览。

## 验证

- Server 测试覆盖响应 envelope、ETag 和原始 `TITLE`/`ARTIST` 键。
- TestMusic MP3/FLAC 音频 API 集成测试同时读取 raw-tags，确认真实 TagLib 扫描后的键值可访问。
- Inspector 与 Real API 测试覆盖展开面板和 endpoint URL。

## 边界

原始标签面板是只读诊断视图；普通编辑仍只允许统一 patch 字段，避免用户误改格式私有键。后续可增加原始键的搜索、复制和高级显式编辑流程。
