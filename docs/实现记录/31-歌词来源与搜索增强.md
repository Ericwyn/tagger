# 歌词来源与搜索增强

> 记录日期：2026-08-20

## 调研结论

本次参考 [HisAtri/LrcApi](https://github.com/HisAtri/LrcApi) 的公开实现和 README，只借鉴请求链路与容错行为，没有复制其 GPL-3.0 源码。

- 网易云先通过 `cloudsearch/pc` 搜索歌曲，再用 `/api/song/lyric?id=...&lv=-1&tv=-1` 读取 `lrc`、`romalrc`、`yrc` 或 `klyric`；专辑封面来自专辑信息中的 `picUrl`。LrcApi 会优先原文歌词，不把翻译歌词当作原文兜底。
- 酷狗先调用歌曲搜索接口取得歌曲 `hash` 和 `album_id`，再调用 `krcs.kugou.com/search` 得到歌词候选的 `id/accesskey`，最后从 `lyrics.kugou.com/download` 取得 Base64 编码的 LRC；封面通过 `play/getdata` 返回的 `img` 获取。
- LrcApi 的公开服务本身也提示酷狗聚合接口可能较慢或不完全准确，因此 Tagger 仍把这些来源标记为实验性，并保留来源开关和错误隔离。

## 本次实现

1. 新增原生酷狗策略：搜索、歌词候选/下载解码、封面 URL、字符串/数字混合字段和多艺人拆分均有独立适配器。
2. 网易云策略从“只返回元数据”扩展为歌曲搜索、别名匹配、同步歌词和专辑封面，并用标题/艺术家/时长对宽搜索结果排序。
3. LRCLIB 保留精确 `/api/get` 快速路径；艺术家缺失、标签不准确或精确结果 404 时，自动使用 `/api/search`，并尝试去掉版本/现场等括号后缀。
4. 所有来源返回歌词前统一去 BOM、零宽字符和 CRLF 差异；候选标题别名只参与评分，不会未经用户确认写入文件。
5. 歌词焦点的候选抽屉优先展示含歌词的结果；歌词编辑器改为纯色背景，移除每行分隔线。

## 兼容与限制

- 网易云、酷狗网页接口不是稳定的官方开放 API，默认保持关闭并在设置中按需启用；单个来源失败不会阻塞其他来源。
- 封面只把 HTTPS 且命中 provider allowlist 的 URL 保存为短期引用，真正写入前仍经过图片下载、格式和大小校验。
- 未来仍需补充来源级授权/代理配置、长期兼容探测和更完整的候选准确率评估；这些工作继续保留在任务列表中。
