# 实验数据源授权与错误诊断

## 已完成

- 网易云、酷我、酷狗策略新增可选 Cookie 配置，并与已有 Authorization、User-Agent、API URL、请求间隔一起由策略自身声明；敏感值继续由 Registry 脱敏并由 SQLite 加密持久化。
- 三家策略的搜索、歌词和封面请求统一透传 Cookie/Authorization，适配需要网页登录态或临时访问令牌的接口。
- 识别 HTTP 200 但业务 JSON 返回错误的情况：网易云 `code`、酷我 `code/status`、酷狗 `status/error_code` 均转换为 `BusinessError`，不再静默返回空候选。
- Provider 诊断结果增加 `hint`，按 401/403、429、5xx、网络失败和业务错误给出可操作的中文建议；设置页测试面板直接展示提示并保留原始错误和结构化日志。
- 错误分类仍是单个 provider 范围；一个实验性来源鉴权过期时，其他已启用来源仍会返回候选。

## 配置建议

- `Authorization` 字段填写完整请求头值（例如 `Bearer …`）；如果接口依赖浏览器登录态，把 `Cookie` 整行复制到对应字段。
- API URL 和 Cookie 都可能随第三方接口变更；优先在设置页的“测试查询”中验证，再进行批量补全。
