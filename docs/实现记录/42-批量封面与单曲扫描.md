# 批量封面、单曲扫描与顶部运行体验

## 本次实现

- 批量编辑面板新增封面操作：保持不变、替换为同一张图片、删除现有封面。替换时图片在前端转为 base64 传给 batch job，后端重新校验 MIME/像素/大小，并按请求选择原图、500×500 或 1000×1000。
- 批量标签与封面在同一个逐曲目 worker 中顺序安全写入，每一项分别记录 revision diff 和封面前后快照；封面失败不会伪报整批成功。
- 单曲扫描新增 `POST /api/v1/tracks/:id/scan`。扫描器复用完整扫描的格式校验和 TagLib 解析，但只读取目标相对路径，服务层只替换内存中的对应曲目并持久化当前索引快照。
- 普通封面写入/删除、标签、sidecar 和历史恢复成功后都按单曲重读，因此 UI 会立即展示真实封面尺寸和文件大小。
- 系统页的 HTTP 监听地址来自启动参数，只读展示；历史窗口支持 3/5/10/20 次并通过 `limit` 查询后端；封面占位/写前历史开关统一为可访问的滑动开关。
- 播放器移入顶部栏右侧，页面高度不再因选曲发生变化；无选曲时显示“无播放歌曲”，有选曲时支持播放/暂停、单曲循环、进度拖动和时间信息。
