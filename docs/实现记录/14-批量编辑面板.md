# 批量编辑面板

验证日期：2026-08-20

## 操作

曲库多选后，底部操作条的“批量编辑”会打开批量编辑抽屉。当前支持：

- 设置或删除专辑。
- 设置、追加或删除专辑艺术家。
- 设置或删除年份。
- 设置、追加或删除风格，多值输入支持逗号和换行分隔。
- 按当前曲目列表顺序生成音轨号，并同步总音轨数。

每个字段都有独立操作类型；未选择的字段保持原值。面板显示影响文件数、不可写文件数和前 20 首曲目的字段差异。用户确认后，前端按曲目逐个调用现有 revision-guarded 安全标签 API；成功项即时更新索引，失败项保留在选择集中以便检查和重试。

## 边界

批量手工编辑目前是前端编排的逐文件安全写入，不创建持久化 batch job；大批量任务的进度和断点续作仍应迁移到专用 write job。文本查找替换、导出完整 JSON/CSV 预览和更多字段操作待后续补齐。
