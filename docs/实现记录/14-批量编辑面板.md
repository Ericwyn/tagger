# 批量编辑面板

验证日期：2026-08-20

## 操作

曲库多选后，底部操作条的“批量编辑”会打开批量编辑抽屉。当前支持：

- 设置或删除专辑。
- 设置、追加或删除专辑艺术家。
- 设置或删除年份。
- 设置、追加或删除风格，多值输入支持逗号和换行分隔。
- 按当前曲目列表顺序生成音轨号，并同步总音轨数。

每个字段都有独立操作类型；未选择的字段保持原值。面板显示影响文件数、不可写文件数和前 20 首曲目的字段差异。真实后端确认后会创建持久化 `batch_edit` job，由 Go worker 按曲目逐个调用 revision-guarded 安全标签 API；成功项记录 revision，失败项记录 item 状态并可从任务中心重试。Mock 模式保留即时原型流程。

## 边界

文本查找替换、导出完整 JSON/CSV 预览和更多字段操作待后续补齐；当前 batch_edit item 事件仍通过任务快照查看，尚未提供独立 item SSE。

## 测试

- `buildBatchPatch` 覆盖公共字段 set/append/delete 和音轨序号生成。
- 组件测试覆盖操作选择、差异预览和提交 payload。
