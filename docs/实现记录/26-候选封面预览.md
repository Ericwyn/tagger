# 候选封面预览

验证日期：2026-08-20

## 本次完成

- 新增 `GET /api/v1/matches/candidates/:id/artwork` 预览接口。
- 接口只接受 Provider 搜索阶段保存的短期 candidate artwork reference；引用过期或不存在时要求重新搜索。
- 预览复用候选封面下载器的 HTTPS、来源域名、重定向、DNS 公网地址、大小和图片解码校验，不把远程 URL 直接暴露给浏览器。
- 返回使用 `private, max-age=300`，不写入音频文件，也不生成历史记录。
- CandidateDrawer 和审核页只有在真实预览 URL 可用时展示封面；默认空白占位，图片加载失败也保持空白。

- Go server 测试覆盖短期引用、图片响应头和安全下载器注入。
- 前端全量测试和 TypeScript 检查通过。
