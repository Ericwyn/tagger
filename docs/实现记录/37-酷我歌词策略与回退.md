# 酷我歌词策略与回退

## 背景

酷我原先只返回歌曲、专辑和封面，导致在歌词查询场景中候选虽然匹配成功，却不能进入歌词编辑和内嵌写入流程。

## 已实现

- 酷我适配器新增当前网页 JSON 歌词接口：按候选 `musicId` 请求 `songinfoandlrc`，读取 `data.lrclist`、`lrc` 或纯歌词字段。
- `lrclist` 的秒数、毫秒数和 `mm:ss.xx` 字符串统一转换为标准 LRC 时间戳，并保留原始歌词文本。
- 保留旧版 `getNewMuiseByRid` + `newlyric.lrc` lyric key 链路作为回退，以应对网页接口结构变化。
- 歌词接口失败不会丢弃歌曲候选；候选仍可用于元数据和封面匹配，只有歌词字段为空。
- 增加请求间隔、响应大小限制、Origin/Referer 和 User-Agent，避免实验性接口连续请求过快或返回异常大内容。

## 验证

- HTTP mock 覆盖搜索结果与 JSON 歌词拼装。
- HTTP mock 覆盖 XML lyric key 的嵌套节点回退。
- 时间解析覆盖秒数、毫秒数和时钟格式。
- `TAGGER_TEST_MUSIC_DIR=/home/ericwyn/Downloads/TestMusic` 下的扫描、MP3/FLAC/WAV 写入、封面、API 和批量任务集成测试通过。
