# v1.0.3 发布说明

## 跨源智能选择

- 所有已启用数据源的候选结果现在会自动综合成一个「智能选择」方案，排在候选列表首位。
- 系统先对所有候选做录音聚类（标题、艺术家、版本词、稳定标识、时长），再做发行版本聚类（专辑、专辑艺术家、年份、音轨号），然后逐字段择优合并。
- 满足以下全部条件时，智能候选会被自动标记接受，无需手动操作：录音匹配度 ≥ 94%、与次优聚类分差 ≥ 8%、无字段冲突、且存在两个以上独立来源或稳定标识（ISRC / MusicBrainz / AcoustID）确认。
- 每个字段保存主来源及确认来源，审核页逐字段展示真实数据源名称。
- smart 候选展示跨源证据卡：录音匹配分、发行匹配分与分差。
- 保留 `ai` 候选类型接口；模型服务未配置时显示明确占位状态，不伪造结果。
- LrcApi 聚合适配器可以贡献字段，但不计入自动接受所需的独立来源数。

## 评分算法改进

- 标题匹配新增版本词分离：live、remix、remaster、acoustic、instrumental 等中英文词组从基础标题中剥离后单独比较，版本词冲突的候选不会进入同一聚类。
- 稳定标识（ISRC / MusicBrainz Track ID / AcoustID）命中时置信度直接提升至 99%；冲突时上限降至 25%。
- 艺术家相似度改用集合交集与字符串相似度的最大值，减少多艺术家拼接的误判。
- 排序优先展示推荐候选，其次按资产质量（有无封面/歌词）和字段完整度排序。

## 查询与文件名解析

- 匹配搜索时自动携带文件已有的 ISRC、MusicBrainz Track/Release ID、AcoustID，提高稳定标识命中率。
- 文件名路径提示自动剥离音轨序号前缀（如 `01 -`、`02.`、`CD1 03 -`）。
- 文件名分隔符扩展支持全角短横线（` – `）和全角长横线（` — `）。

## 交互改进

- 候选列表和候选选择器按「推荐方案」/「原始数据源」分组呈现。
- 工具栏「接受所有高置信」改为「接受所有自动推荐」，判断依据统一由后端 `autoAccept` 标志决定，不再在前端硬编码分数阈值。
- 审核页加载失败与空结果各有独立错误状态页，支持一键重试。

## 验证

- Go 全量测试、静态检查及构建通过。
- 前端 TypeScript 检查和 Vite 生产构建通过。
