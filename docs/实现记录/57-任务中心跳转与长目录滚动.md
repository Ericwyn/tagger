# 任务中心跳转与长目录滚动

## 批量抓取入口

- 真实模式创建批量抓取任务后立即跳转任务中心，不再等待候选抓取完成。
- 任务中心使用任务 ID 一次性聚焦新任务；后续轮询不会抢回用户手动选择的其他任务。
- 任务中心继续提供实时进度、取消和完成后打开审核页的入口。

## 目录树可读性

- 树状目录名称使用独立的可测量标签，短名称保持原样，超出侧栏宽度时悬停会平滑横向滚动。
- `title` 属性保留完整目录名，键盘/辅助技术用户不依赖动画也能查看完整文本。
- 尊重 `prefers-reduced-motion`，减少动态效果时不执行滚动动画。

## 验证

- 新增任务排队后立即回调和任务中心聚焦测试。
- 新增长目录完整名称可访问性测试。
