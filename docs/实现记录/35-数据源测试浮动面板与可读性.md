# 数据源测试浮动面板与可读性

## 目标

数据源测试需要能输入临时查询并查看完整诊断结果，同时避免把测试内容挤在设置页卡片流中。页面中的辅助文字也不应使用 7–10px 的过小字号。

## 已实现

- 设置页的“测试查询”改为通过 React Portal 挂载到 `document.body` 的浮动面板。
- 面板提供歌曲名、歌手、专辑和时长输入，支持遮罩、关闭按钮关闭。
- 候选结果继续展示封面状态和匹配度；有歌词时显示“查看歌词”折叠区，展开后查看原始 LRC/纯文本内容。
- 查询结果下方保留候选计数、延迟、缓存状态和结构化抓取/封面探测日志，方便定位数据源问题。
- 全局 CSS 将辅助性文字的最小字号统一调整为 11px；标题、正文和数据字段仍按语义保留更大的层级。
