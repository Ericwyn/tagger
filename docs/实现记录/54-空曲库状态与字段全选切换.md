# 空曲库状态与字段全选切换

## 空曲库启动状态

- 如果启动参数没有提供音乐目录，程序会优先恢复仍存在的最近活动目录。
- 如果持久化目录已经被移动或删除，会清除失效的活动目录指针，但保留旧索引作为后续可选曲库。
- API 现在始终返回 `active: true/false`，前端不会把一个未活动的旧索引误当作当前曲库。
- 没有活动曲库时，曲库页显示明确的“打开设置添加曲库”入口；设置页仍可看到已注册但未活动的曲库。

## 候选字段选择

- 候选抽屉的“全选”按钮只作用于当前候选实际提供的字段。
- 当前全部可用字段已选中时，按钮变为“全不选”；再次点击会清空字段，再点击可恢复全选。
- 该状态只影响写入 patch，不会自动写入缺失字段或附加资源。
