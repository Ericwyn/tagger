# 批量标签查找替换

> 记录日期：2026-08-20

## 功能

批量编辑现在支持对标题、艺术家、专辑、专辑艺术家、风格、注释、作曲家、指挥、作词家、版权和 ISRC 执行“查找替换”。替换操作会：

- 在前端显示独立的“查找内容”和“替换为”输入框，并在提交前生成逐曲目差异预览；
- 允许替换为空，用于批量清理 `[Live]`、`(原唱)` 等导入噪声；
- 对列表字段逐项替换，清理空值并去重，保持原列表顺序；
- 由 Go 后端校验字段和查找内容，继续使用每个文件的 base revision、临时副本、重读校验和原子替换；
- 复用现有 batch_edit worker、逐文件状态、失败重试和批量历史记录。

年份和 BPM 等数值字段不支持文本替换，仍使用设置/删除操作。

## 验证

- 前端替换输入、预览、空查找保护和提交 payload 测试。
- Go patch 生成、API 参数校验和真实 TestMusic 批量 worker 覆盖标题/列表替换。
