# 审核资源预览与候选封面排序

## 已完成

- LrcApi 返回的 Apple Music、网易云、酷我、酷狗和 MusicBrainz 已知 CDN 地址现在可以通过受控 allowlist 探测；仍拒绝未知域名、内网地址和不安全重定向。
- 候选评分对没有封面引用的结果设置人工审核上限，并在匹配原因中标注“来源未提供封面”，使有封面的候选优先且不会被自动归为高置信。
- 审核对比表的歌词和封面行增加详情按钮。歌词模态同时展示当前内嵌歌词和候选歌词；封面模态并排展示当前封面、候选封面和候选图片尺寸。
- 封面写入尺寸保留在对比表下方，但删除重复的“同时写入候选封面”复选框；是否采用封面只由对比表的“替换封面”字段控制。

## 验证

- Provider 测试覆盖 LrcApi 已知上游 CDN 放行、未知域名拒绝和无封面候选降权。
- ReviewPage 测试覆盖歌词/封面详情模态的打开、Escape 关闭以及候选切换后的连续审核。
