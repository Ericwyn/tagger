# 多数据源并行限流与来源代理

> 日期：2026-09-01

## 行为

- 单首曲目的已选数据源继续并行查询；批量任务仍逐曲处理。
- 每个数据源拥有独立 Gate，同一来源最多一个在途 HTTP 请求。许可在响应体读完或关闭后释放，因此搜索、详情、歌词、自动重试和封面下载不会互相绕过限流。
- 所有内置来源新增 `proxyUrl`。显式填写的无鉴权 HTTP(S) 代理覆盖该来源的 API 与封面流量；留空继续使用 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`，否则直连。
- 配置保存后立即替换该来源的 transport 并关闭旧空闲连接；恢复默认配置会清空代理。配置继续存放在已有的加密 Provider JSON 中，不需要 SQLite migration。

## 安全与诊断

- 代理 URL 禁止 SOCKS/PAC、用户信息、路径、查询参数和片段；本机代理所需的 loopback/IP 地址允许使用。
- 使用代理不会放宽候选封面域名白名单、重定向校验、图片格式、大小和尺寸验证。MusicBrainz Archive 镜像与网络代理保持两个独立配置层。
- 数据源测试强制实时查询并直接探测封面，不读取之前的 Provider 或封面缓存；成功查询会刷新正常缓存。

## 验证

- 同步屏障验证跨来源并行，响应体生命周期与取消测试验证同源单在途请求。
- 覆盖自动重试间隔、运行时限流修改、显式代理路由、环境代理继承、非法代理拒绝、配置持久化/重置和封面安全策略。
- 前端覆盖代理字段保存、清空和恢复默认提示。
