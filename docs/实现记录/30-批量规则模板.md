# 批量规则模板

## 本次完成

- 批量编辑面板可将字段设置/追加/删除操作和“按选中顺序生成音轨号”保存为模板。
- 模板按名称更新，最多保留 20 条，保存于浏览器本地；载入模板只恢复规则，不覆盖当前选择的曲目。
- 真实后端模式仍创建原有 `batch_edit` job，因此 revision 冲突、逐文件结果、失败重试链路不变；Mock 模式继续直接验证逐文件写入。

## 边界

模板目前是用户侧规则模板，还没有按目录/专辑自动匹配的规则引擎；目录模板和更细粒度的跨文件编排列入后续主线。

## 验证

- BatchEditPanel 测试覆盖模板保存、关闭重开后的载入，以及扩展元数据字段操作。
