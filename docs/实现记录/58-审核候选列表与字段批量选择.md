# 审核候选列表与字段批量选择

## 已完成

- 审核页“更换候选”会展开当前曲目的全部候选，不再只按结果顺序循环。
- 候选列表展示来源、外部 ID、匹配度、匹配等级以及封面/歌词能力；点击任意候选即可切换当前对比值。
- 切换候选后字段选择按新候选重新计算，封面选择重置，审核状态回到待确认并持久化选中的候选 ID。
- 对比表格底部增加“全选字段 / 全部取消”操作，只作用于当前候选实际提供的字段，并保持逐字段 checkbox 可继续微调。
- 新打开的审核项只默认勾选候选值与当前值不同的字段；值相同的字段保持未选中，避免无意义写入。重新选择候选后也会按同一规则重算。
- 封面写入不再依赖对比表格中的隐含行，审核详情提供独立的“同时写入候选封面”复选框和原图/1000×1000/500×500 尺寸选择器。
- 关闭生成式封面占位后，审核列表、当前值、候选值和候选选择器在没有可用图片或图片加载失败时统一保持空白，不再短暂显示自动生成封面。

## 验证

- 更新审核页测试，覆盖从三条候选中直接选择 Apple Music 候选。
- 覆盖全选字段和全部取消后逐字段状态同步变化。
- 覆盖相同值字段默认不选、封面写入复选框和尺寸选择。
- 增加 `CoverArt` 回归测试，确保关闭生成式占位时无图片不会渲染标题/艺术家占位内容。
