# 批量扩展字段策略

验证日期：2026-08-20

## 本次完成

- 批量编辑面板增加注释、作曲家、指挥、作词家、版权、BPM、ISRC。
- 单值字段只允许设置/删除；作曲家和作词家支持设置/追加/删除；BPM 只接受 1–1000 的整数。
- Go API 与 worker 使用同一套字段白名单和 patch 编译规则，重复字段、空值、非法追加和非法 BPM 会在入队前拒绝。
- 任务中心的逐文件 diff 标签同步覆盖这些字段；既有 revision 冲突、失败项重试和审计历史链路不变。
- MusicBrainz/AcoustID 等识别 ID 暂不开放批量改写，仍通过单曲 Inspector 或候选审核逐曲确认，避免跨文件写入错误标识。
