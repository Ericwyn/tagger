# 切换曲库后的筛选状态恢复

## 背景

侧栏支持切换多个已注册曲库后，页面会重新加载活动曲库和曲目索引。旧实现只替换曲目数据，仍保留原曲库的目录筛选和选中曲目；当新曲库不存在同名目录时，列表会被旧筛选条件过滤为空，容易误以为切换失败。

## 已完成

- `LibraryPage` 每次加载曲库时根据活动曲库重新校正目录状态。
- 曲库切换使用全量加载路径，清理旧目录、智能筛选和批量选择状态，并把选中曲目重置为新曲库的第一首。
- 重新扫描使用保留选择路径：只有目录仍存在且选中曲目仍在新索引中时才保留，避免扫描后丢失用户上下文。
- 新增页面级回归测试，验证从 `TestMusic` 切换到 `Archive` 后展示第二个曲库的曲目，而不是旧目录的空列表。

## 验证

- 前端 TypeScript 检查、Vitest 全量测试和 Vite 生产构建通过。
- Go 全量测试通过。
