# 候选歌词编辑与内嵌写入

## 背景

歌词查询结果不能只通过一个“同时写入歌词”开关决定写入。用户需要先看到远程返回的具体内容，修正错字或时间轴，再决定是否写入音频文件。

## 已实现

- 候选匹配抽屉在候选详情中增加“歌词内容”编辑区，展示来源和完整歌词文本。
- 文本框默认填充当前候选的远程歌词，支持直接编辑多行 LRC/纯文本内容。
- “同时写入歌词”说明更新为“写入上方编辑后的歌词”；未勾选时继续保留当前文件中的歌词。
- 应用候选时将编辑后的歌词放进已有 `TrackPatch.lyrics`，沿用原有 revision、原子写入、重读校验和历史审计链路；不生成 `.lrc` sidecar。
- 远程候选没有歌词时不展示编辑区，避免让空白占位误导为可用歌词。
