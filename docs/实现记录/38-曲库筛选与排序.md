# 曲库筛选与排序

## 背景

曲库工具栏原先只有视觉上的“筛选”和“专辑顺序”按钮，点击不会改变列表。真实音乐目录中 MP3、FLAC、WAV 混排时，需要快速聚焦某种格式或按不同方式检查文件。

## 已实现

- 新增 MP3、FLAC、WAV 和全部格式筛选。
- 新增专辑/音轨顺序、标题、最近修改、格式四种排序。
- 筛选和排序同时作用于曲目列表、批量补全范围、全选和快照导入范围，避免只改变视觉顺序而产生误操作。
- 继续使用现有侧边栏健康状态、目录和文本搜索条件，多个条件会叠加。

## 验证

- App 集成测试验证 TestMusic Mock 曲库从 24 首筛到 15 首 FLAC，并验证排序选择状态。
- `npm run lint` 与前端全量测试通过。
