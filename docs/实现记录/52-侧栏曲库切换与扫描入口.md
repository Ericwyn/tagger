# 侧栏曲库切换与扫描入口

## 已完成

- 曲库页加载 `/api/v1/libraries` 后将当前活动曲库和全部已注册曲库交给侧栏；没有活动标记的旧数据会以当前首项作为兼容回退并在前端标记。
- 顶部“ACTIVE LIBRARY”切换器展开后显示曲库名称、根路径和当前状态，切换调用已有受保护的扫描任务，扫描完成后刷新曲目与目录树。
- 切换期间其他曲库按钮禁用并显示进度图标，失败只提示错误，不替换当前页面索引。
- 侧栏同步行的重新扫描按钮现在复用曲库页扫描逻辑；“管理曲库”入口跳转设置页，避免静态按钮造成误导。
