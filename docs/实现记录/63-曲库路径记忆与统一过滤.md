# 曲库路径记忆与统一过滤

## 浏览状态

- `LibraryPage` 使用 `tagger-library-browse-state-v1` 在浏览器本地保存每个曲库的最近目录 ID、目录路径和“含子目录”状态。
- 曲库页面重新挂载（例如从任务中心返回）或切换到已注册曲库后，会校验保存的目录是否仍存在；有效时恢复选中目录并自动展开树状目录的所有祖先节点。
- 目录选择仍然只影响当前页面范围，不把筛选状态写入 URL，避免刷新时生成难以阅读的长查询参数。

## 递归目录

- 顶部过滤栏新增“含子目录”复选开关。未选中时只显示当前目录的直接歌曲；选中后按规范化目录路径前缀收集所有子目录 Folder ID。
- 没有直接歌曲的父目录也可选中；此时打开开关即可显示它的全部后代曲目。
- 目录、状态、格式和文本搜索采用 AND 关系，可以在某个深层目录内继续筛选缺歌词、缺封面或解析失败的文件。

## 智能筛选迁移

原侧栏的“全部音乐、资料完整、缺少封面、缺少歌词、需要确认、解析失败”入口已合并为列表顶部的“状态”下拉条件。侧栏只保留曲库切换和目录树，减少两套筛选入口造成的状态歧义。

## 验证

- `LibraryPage.test.tsx` 覆盖返回后恢复深层目录、父目录递归展示和状态下拉筛选。
- 前端 lint、109 个 Vitest 测试和 Vite 生产构建均通过。
