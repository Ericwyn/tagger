# 设置页曲库状态与重新扫描

## 已实现

- 设置页“音乐目录”标签不再展示固定的 TestMusic 文案，而是读取 `/api/v1/libraries` 的当前曲库摘要。
- 显示受控根目录、曲目数量、文件夹数量、最近扫描时间和可写状态。
- “重新扫描”复用现有曲库扫描 job API，真实模式会等待 job 完成并提示结果，Mock 模式也能完成可测试的原型流程。
- “添加目录”按钮明确提示当前单二进制通过 `--music-dir`/`TAGGER_MUSIC_DIR` 配置根目录，避免点击后无反馈；动态多目录注册仍保留在后续主线。

## 验证

- SettingsPage 测试覆盖加载 TestMusic 曲库摘要和触发重新扫描。
- `npm run lint` 与设置页测试通过。
