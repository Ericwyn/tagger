# 跨源智能选择首版

> 日期：2026-09-01

## 已实现

- 文件级搜索和批量匹配在保留全部原始 Provider 候选的同时，增加一个 `smart` 复合候选。
- 所有本次启用的数据源都进入 Recording 候选池；版本词、稳定 ID、艺术家、时长参与跨源聚类。
- Recording 内按 Release ID、专辑、专辑艺术家和年份分组，发行字段不跨版本多数投票。
- 每个字段保存主来源、确认来源和字段置信度；智能候选保存成员候选、贡献来源、分差、冲突和算法版本。
- 身份分、发行分、字段完整度和资源质量拆开；没有封面不再压低身份匹配度。
- `LrcApi` 聚合候选可以贡献字段，但不计入自动接受所需的独立来源。
- 智能封面通过原始候选引用下载，继续使用真实 Provider 的代理、安全校验、缓存和 source-wide Gate。
- 服务端持久化推荐候选和保守的自动接受状态；自动接受仍不会直接写文件。
- 单曲抽屉和批量审核页按“推荐方案 / 原始数据源”分组，并逐字段展示真实来源。
- 保留 `ai` 候选类型；模型未配置时明确显示占位状态，不伪造 AI 结果。

## 验证重点

- 三个不同能力来源可合成元数据、歌词、稳定 ID 和封面。
- 精选集来源数量更多时，本地明确的原专辑仍保持发行字段一致。
- Live 与 Remix 不会进入同一 Recording 聚类。
- 智能封面引用和历史来源可以通过现有写入链路安全处理。
- 文件名前缀与 Unicode 分隔符生成的歧义提示不污染真实标签。
