# 标签快照导入导出

## 本次完成

- 曲库工具栏新增“标签快照”，可对当前筛选范围或已选择曲目导出 JSON/CSV。
- 快照覆盖标题、艺术家、专辑、音轨/光盘号、年份、歌词、扩展内嵌字段和识别 ID；不导出技术属性、绝对路径或远程封面 URL。
- 导入支持 JSON 数组/`tracks` 包装格式和带引号、多行歌词的 CSV；按稳定曲目 ID 优先、相对路径兜底匹配。
- 导入先展示逐曲目差异、未匹配数量和 revision 漂移，再调用现有安全标签写入接口逐文件应用。
- 导入成功后保留本次导入前的曲目快照，曲库中可执行一次会话内撤销；若撤销前曲目又发生变化，则停止并提示通过修改历史逐曲恢复。

## 边界

- 当前撤销按钮只针对最近一次快照导入，浏览器刷新后不保留撤销上下文；每次实际写入仍生成独立 revision，可在历史页恢复。
- 批量编辑任务的模板化编排和跨文件部分失败恢复仍在后续主线中。

## 验证

- 快照 JSON/CSV 多值字段、歌词换行、相对路径匹配、revision 漂移和导入预览均有 Vitest 覆盖。
