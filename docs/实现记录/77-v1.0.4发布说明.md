# v1.0.4 发布说明

## Ogg Vorbis 与 Ogg Opus

- 曲库完整支持 `.ogg` 和 `.opus` 文件的扫描、索引、筛选、单曲重扫与目录变化监听。
- Ogg Vorbis 与 Ogg Opus 统一归入 `ogg` 容器格式，并通过技术信息中的 codec 区分实际编码。
- 标签、歌词 sidecar、嵌入封面、安全写入和历史恢复全部接入现有流程，无需 FFmpeg、CGO 或系统 TagLib。
- 浏览器试听与 Range 请求使用 `audio/ogg`；未知扩展名会被明确拒绝，不再隐式当作 FLAC 处理。

## 批量处理上限

- 单次批量曲目上限由固定 1000 首改为后台可配置，默认提高到 2000 首。
- 可在「设置 → 系统与安全」中调整为 1–100000 首，配置写入 SQLite 并立即生效，无需重启。
- 曲目解析、全选、批量匹配、批量补全和批量编辑统一使用同一上限，超限提示会显示当前配置值。

## 曲库界面与目录树

- 较窄桌面宽度下，右侧曲目信息面板改为显式抽屉，避免覆盖歌曲列表；更窄时左侧目录也切换为抽屉。
- 长目录名不再使用持续滚动动画：默认稳定省略，悬浮或键盘聚焦后在页面顶层显示完整名称与相对路径，不受侧栏裁剪。
- 当前目录使用浅色强调和左侧标记，减少大面积深色选中态带来的视觉干扰。
- 桌面端目录栏支持 210–420px 拖拽调整，宽度会在浏览器中记忆；也支持方向键微调和双击恢复响应式默认值。

## 审核体验

- 候选来源选择列表现在直接展示歌手；无歌手信息时显示明确占位，减少同名歌曲的误选风险。

## 升级提示

- 系统设置会自动使用新的 2000 首默认批量上限，不需要数据库迁移或手工修改配置。
- 升级后建议对已有曲库执行一次快速扫描或完整扫描，以便把过去未识别的 `.ogg`、`.opus` 文件加入索引。

## 验证

- Go 全量测试通过。
- 前端 133 项测试、TypeScript 检查和 Vite 生产构建通过。
