# 网易云与酷我实验性适配器

验证日期：2026-08-20

## 调研结论

当前公开资料显示，网易云和酷我没有与 MusicBrainz/iTunes 等价的稳定开放开发者 API。社区项目通常调用网易云网页搜索 `/api/cloudsearch/pc`，酷我网页搜索 `search.kuwo.cn/r.s`；这类接口可能随网页版本、地域、频控或服务条款变化。因此本项目没有把它们标成“连接正常”的官方 provider。

参考：[NeteaseCloudMusicApi](https://github.com/metowolf/NeteaseCloudMusicApi)、[ncma Go 实现](https://github.com/withlin/ncma)、[酷我网页接口分析](https://gist.github.com/Domdkw/91972dfe7b96ed2713afbb18ae2ed262)。

## 已实现

- `internal/providers/netease`：网页搜索 JSON 映射标题、歌手、专辑、时长、音轨和封面 URL。
- `internal/providers/kuwo`：网页搜索 JSON 映射标题、艺人、专辑、专辑艺人、时长、音轨和封面 URL。
- 两者均使用统一 `GetJSON` 响应上限、context、User-Agent 和 HTTP 错误模型。
- 默认 `Enabled=false`、`Experimental=true`、健康为 `degraded`；设置页显示实验性非官方接口。
- 启用后进入 Registry 的并行搜索、SQLite TTL 缓存和候选评分，不会阻断 MusicBrainz/Apple/LRCLIB。
- 候选封面仍需通过 provider 域名 allowlist、DNS 公网检查、图片大小/MIME/解码校验。

## 测试

两个适配器都使用自定义 RoundTripper fixture，无外网和监听端口依赖，覆盖查询参数、JSON 字段、歌手拆分、时长解析、外部 ID 和封面 URL。

默认主流程不会自动启用它们；启用后的真实连接测试由用户在设置页主动触发，失败会显示 `provider_test_failed`，不会把失败来源作为整体抓取失败。

## 当前边界

- 网易云部分需要更复杂的 weapi/登录态接口才能补齐歌词和所有发行字段，本版只实现公开搜索元数据。
- 酷我字段命名和图片 URL 可能变更，适配器保持独立，fixture 失败时可以单独修复。
- 未实现绕过版权限制、音频下载或登录态模拟；本项目只抓取用户明确请求的元数据和封面候选。
- 正式生产使用建议优先配置 MusicBrainz、Apple/iTunes、LRCLIB 或获得明确授权的官方接口。
