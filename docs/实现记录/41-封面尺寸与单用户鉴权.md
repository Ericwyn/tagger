# 封面尺寸控制与单用户鉴权

## 本次完成

- 扫描器读取第一张嵌入封面的宽度、高度和字节数，曲目检查器展示实际尺寸；远程候选封面在加载后展示自然尺寸。
- 封面写入前可以选择保留原图，或居中裁剪并缩小到 1000×1000 / 500×500。只缩小不放大，PNG 保持 PNG，JPEG 保持 JPEG，WebP 在裁剪输出时转为 JPEG；输出会再次经过图片大小、像素和 MIME 校验。
- 数据源诊断结果的封面使用固定方形容器和 `object-fit: cover`，长方形来源不会撑开结果卡片。实验性说明和配额说明改为卡片内自适应布局，不再互相覆盖。
- 顶部导航移除尚未实现的快捷键、通知和账户入口，也移除常驻任务红点；播放器和主题切换仍保留。
- 增加可选单用户令牌：启动参数 `--auth-token` 或环境变量 `TAGGER_AUTH_TOKEN`。令牌为空时 API 保持本地开发的免鉴权行为；配置后 API 接受 `Authorization: Bearer <token>` 或 `X-Tagger-Token`，前端首次访问会显示令牌输入页。首次成功的令牌请求会换取 HttpOnly、SameSite cookie，让原生图片、音频和 SSE 请求也能通过鉴权；健康检查和静态前端资源保持公开，便于启动探活。
- 任务中心 SSE、图片和音频请求都通过同源 cookie 继承鉴权；普通 GET 轮询仍保留为断线后的权威快照恢复。
