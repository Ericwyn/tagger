# v1.0.5 发布说明

## 数据源可用性修复

- 酷狗搜索迁移到当前可用的 `songsearch.kugou.com` 接口，兼容新的响应字段、搜索高亮和搜索结果内封面；旧 `mobilecdn` / `msearchcdn` 配置会自动迁移。
- 酷我封面不再使用证书失效的 `*.kwcdn.kuwo.cn`，新候选和已缓存的旧封面引用都会安全改写到 `img4.kuwo.cn`。
- 酷我歌词改用当前 `openapi/v1/www/lyric/getlyric` 接口，并保留旧 RID 歌词链路作为兼容回退。
- Apple / iTunes 默认 storefront 从当前返回空目录的 `CN` 调整为 `HK`；旧 CN 配置会自动迁移，中文和国际曲库搜索恢复正常。
- 远程封面下载器显式启用 HTTP/2，修复部分 Apple、网易云和 Cover Art Archive CDN 响应被误判为损坏 HTTP/1 数据的问题。

## 歌词与候选质量

- 网易云现在读取并按时间戳合并 `lrc` 与 `tlyric`，英文歌曲可以同时获得原文和中文翻译。
- 网易云只为最终可能返回的候选获取歌词，不再为随后丢弃的候选发送额外请求。
- 酷我搜索兼容当前响应中的秒数时长字段，候选时长评分更准确。

## 批量抓取性能

- 自动批量抓取从每个来源保留 5 个候选调整为 2 个；审核页手动重新匹配仍保留每源 5 个候选。
- 匹配任务使用最多 2 首曲目的受控流水线，在慢来源等待期间继续处理其他来源。
- 每个数据源仍由同一个 Gate 保证最多一个在途请求，曲目流水线不会绕过来源限流。
- 旧 Apple CN 设置会在启动时持久化迁移到 HK，避免每首歌重复触发约 3 秒的空目录回退。

## 数据源诊断 CLI

- 新增 `--test-providers`，无需启动 Web 服务或扫描曲库即可测试全部内置来源，包括设置中暂时关闭的实验来源。
- 诊断会绕过搜索缓存，汇总候选、歌词、封面和延迟，并默认真实下载、解码和校验候选封面。
- 支持自定义标题、歌手、专辑、时长、每源候选数，以及 `--test-json` 机器可读输出。
- 搜索或封面探测失败时退出码为 `1`；零候选或缺少可选资产记为 warning。

```bash
./tagger --data-dir ./data --test-providers

./tagger --data-dir ./data --test-providers \
  --test-title "Easy On Me" \
  --test-artists "Adele" \
  --test-album "30" \
  --test-duration 225 \
  --test-limit 2 \
  --test-json
```

## 升级提示

- 数据源端点和 Apple storefront 的内置旧值会在启动时自动迁移并持久化，无需手工清空数据库或 Provider 缓存。
- 网易云、酷我和酷狗仍属于实验性网页接口，默认启用状态不变；升级不会替用户打开已关闭的来源。
- 自动批量抓取候选数变为 2；需要查看更多版本时，可在审核页使用手动重新匹配。

## 验证

- Go 全量测试通过，并对匹配流水线与 Provider Registry 运行 race detector。
- 前端 134 项测试和 TypeScript 检查通过。
- 使用真实端点完成全部来源搜索、歌词与封面诊断；Apple、网易云、酷狗和 LrcApi 封面均完成实际下载校验。
